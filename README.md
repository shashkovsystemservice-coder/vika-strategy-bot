# Vika Strategy Bot

Облачный Telegram-бот для последовательного сбора стратегических ответов по проектам Вики.

## Архитектура

Telegram → Vercel Functions → Supabase → Gemini API

- **GitHub** — код и версия опросника.
- **Vercel** — выполнение серверной логики и webhook Telegram.
- **Supabase** — вопросы, ответы, транскрипты и оригинальные аудиофайлы.
- **Gemini API** — транскрибация голосовых сообщений и, позднее, структурирование ответов.

## Принцип обновления

Опросник хранится отдельно от программной логики в `data/questions.json`. Поэтому вопросы можно менять без переписывания бота. После подключения репозитория к Vercel любой commit в `main` автоматически создаст новый production deployment.

## Текущий этап

1. Создана первая версия стратегического опросника IBA Wellness.
2. Добавлен публичный API для проверки списка вопросов.
3. Telegram, Supabase и Gemini будут подключены после добавления секретов в Vercel Environment Variables.

## Будущие переменные окружения

Ни один секрет не хранится в GitHub.

```text
TELEGRAM_BOT_TOKEN
TELEGRAM_WEBHOOK_SECRET
GEMINI_API_KEY
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
```

## Главный принцип данных

Для каждого ответа сохраняются отдельно:

- исходный вопрос;
- оригинальное аудио;
- дословная транскрипция;
- структурированный ответ;
- статус ответа;
- дата и источник;
- уточняющие вопросы.

Так исходная речь Вики никогда не подменяется интерпретацией ИИ.
